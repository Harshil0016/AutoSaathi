# 🛺 AutoSaathi

### Your Saathi for Every Ride

AutoSaathi is a responsive UI/UX design concept for an Indian auto-rickshaw booking platform that helps users quickly find, select, and book nearby auto-rickshaws with an easy and affordable ride-booking experience.

---

## 📌 About the Project

**AutoSaathi** is a UI/UX design project created in **Figma** for a simple and user-friendly auto-rickshaw booking experience.

The platform is designed for Indian users who need affordable and convenient transportation for daily travel. Users can enter their pickup and destination, view available auto options, check estimated fares, and confirm their ride.

The design focuses on simplicity, accessibility, responsive layouts, and an Indian transportation experience.

---

## 🎯 Project Goals

- Create a simple and friendly auto-booking experience.
- Help users find nearby auto-rickshaws quickly.
- Provide clear pickup and destination selection.
- Show estimated fare before booking.
- Make the interface easy to use for daily commuters.
- Create responsive designs for Desktop, Tablet, and Mobile.
- Use a modern Indian mobility-focused visual style.
- Maintain consistent typography, colors, spacing, and components.

---

## 📱 Responsive Design

The AutoSaathi design is created for three different screen sizes:

1. **Desktop** — Main wide-screen layout
2. **Tablet** — Medium-screen responsive layout
3. **Mobile** — Compact mobile layout

The layouts are adapted rather than simply scaled down so that the interface remains easy to use on every device.
